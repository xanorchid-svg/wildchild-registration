# Wild Child Nosara website (static rebuild)

Static site rebuilt from the Wix site. Edit pages in `_source/pages/`, shared layout in `_source/_header.html` / `_source/_footer.html`, styles in `_source/styles.css`, then run `python3 _source/build.py` and copy `site-build/*` to the repo root.

Images are served from Wix's image CDN (static.wixstatic.com) with responsive sizes.
